# 使用说明 / How to use

TEAM JBYangC 战队官网。**纯离线静态网页**，双击 `index.html` 就能看全站，
不需要联网、不需要服务器、不需要装任何软件。

站点位置：`D:\LittleProject\JBYangC\site\`

---

## 一、打开就能用（素材已就位）

站点是完全自包含的：所有素材都在站点自己的 `assets\media\` 里，**已经复制好了**，
不需要再做任何准备。

双击 `D:\LittleProject\JBYangC\site\index.html` 即可浏览全站。

### 确认素材完好

双击 `test.html`，它会逐行列出每个素材的加载状态：

- 全部显示 **OK + 尺寸** → 环境正常，回去双击 `index.html` 即可
- 有行显示 **失败** → 那个文件不在了，对照下面的结构补回去

## 二、日常使用

**双击 `index.html`** 就行。

- 右上角可以切换 **中文 / 英文**
- 右上角可以切换 **黑夜 / 白天 / 跟随系统** 外观
- 手机、平板也能直接打开，导航会自动收进汉堡菜单

**分享给别人**：把整个 `site` 文件夹压缩成 zip 发出去，对方解压后双击
`index.html` 即可，不需要任何配置。

---

## 三、以后自己改内容

**99% 的情况只需要改一个文件：`assets\js\data.js`**

用记事本或 VS Code 打开它，里面按段落分好了：

| 想改什么 | 改哪里 |
| --- | --- |
| 队员名单、位置、简介 | `ROSTER` 数组 |
| 队员照片、印花、签名路径 | 同上，每位队员的 `photos` / `sticker` / `signature` |
| 平台战绩（战力、段位、指标、雷达） | `PLAYER_STATS` 对象 |
| 赛事记录 | `MATCHES` 数组（现有 1 条：2024-12-22 东北Major） |
| 队徽、队服、合影、视频 | `CREST` 与 `MEDIA` |
| 关注渠道（B 站等） | `CONTACT` 数组 |
| 战队名、建队时间 | `SITE` 对象 |

**加一位新队员**：在 `ROSTER` 里复制一段已有的，改掉 `id`、`handle`、`role`、
`photos` 等字段即可。首页、阵容页、素材库、选手详情页会**自动出现**这个人，
不需要改任何 HTML。

**换一张照片**：把新图片放进对应的文件夹，然后在 `data.js` 里改路径。
路径写法就是 `asset('选手照片/队员名/文件名.webp')` —— 中文和括号直接写，
程序会自动处理编码。

## 五、站点结构说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 首页：战队主张、队员一览、合影、素材预览、关注入口 |
| `about.html` | 战队介绍：正文、理念、队内约定、历程 |
| `players.html` | 选手阵容：可按位置筛选 |
| `player.html` | 选手详情模板，靠 `?id=YangC` 这样的参数识别是谁 |
| `matches.html` | 赛事记录（表格已就绪，数据在 `data.js` 的 `MATCHES` 里） |
| `media.html` | 素材库：队徽动画、入场动画、队徽版本、队服、合影、选手印花 |
| `follow.html` | 关注我们：B 站频道、其他渠道、常见问题 |
| `test.html` | 素材自检页，诊断用，可以删 |
| `assets/css/style.css` | 全站样式与配色变量 |
| `assets/js/data.js` | **数据层，日常改这个** |
| `assets/js/main.js` | 行为层（导航、双语、主题、动画），一般不用动 |

配色想换的话，改 `style.css` 最上面 `:root` 里的 `--cyan`、`--sky`、`--blue`、
`--indigo` 四个值就行（浅色主题在下面的 `[data-theme="light"]` 里），
全站的渐变、按钮、标题会一起跟着变。

## 六、常见问题

**打开后图片是空的，或者右下角弹出「有素材没有读到」？**
说明 `assets\media\` 里有文件缺失。点提示里的链接打开 `test.html`，
能看到具体缺哪些文件，对照第一节的结构补回去即可。

**能直接上网址栏输路径打开吗？**
这个站是给离线双击用的，不需要网址。双击 `index.html` 就是完整效果。

**队员照片显示不出来，但文件确实在？**
打开 `test.html` 看那一行的具体报错。常见原因是文件名被改动过
（比如系统自动加了 `(1)`），对照 `data.js` 里的路径改回去即可。

**想删掉诊断页？**
删掉 `test.html` 即可，其他页面不依赖它。

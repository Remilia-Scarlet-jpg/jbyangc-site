# TEAM JBYangC 战队站点

一支 CS 业余娱乐向战队的官方网站。**纯离线静态网页**：双击 `index.html` 即可浏览全站，
无需联网、无需服务器、无需数据库、无需任何第三方运行环境。

界面风格：简约 + 青蓝渐变，支持**黑夜 / 白天 / 跟随系统**三态外观，中英双语。

> 素材已全部就位（`assets\media\`，70 个文件、约 7.7 MB），**打开即可用**。
> 需要排查素材是否完好时看 [使用说明.md](使用说明.md)。

## 一、需求对照

| 网站要求 | 本站做法 |
| --- | --- |
| 纯本地离线、资源全部本地化 | 无任何外链：不引用 CDN、不加载在线字体、不请求远程接口。图标全部内联 SVG，配色全部写在 CSS 里。 |
| 双击首页即可打开 | 素材位于站点内部 `assets/media/`，全部是相对路径，`file://` 协议下不触发跨目录拦截。 |
| 电脑 / 手机均可打开，无系统版本限制 | 纯 HTML + CSS + JS（ES5 语法），无框架、无构建产物。响应式布局，880px 以下自动收进汉堡菜单。 |
| 离线分享、解压即用 | 压缩整个 `site` 文件夹发给他人，解压双击即可。 |
| 代码轻量化、无冗余 | 无依赖库，无打包器。9 个页面共用同一套 `style.css` + `main.js`，数据集中在 `data.js`。 |
| 图片素材内嵌网站本地文件夹 | 见 `assets/media/`，素材由你一次性复制进来。 |
| 排版适配电脑端、整洁简约年轻化 | 1200px 内容宽度居中，栅格化卡片布局，克制的描边与留白。 |
| 低调专业、休闲电竞风 | 深色蓝黑底 + 单一青蓝渐变强调色；动效统一长缓动，不抢内容。 |
| 结构清晰、分类规整 | 页面在根目录，资源按 `assets/css`、`assets/js`、`assets/media` 分类。 |
| 方便自主更新 | 日常只需编辑 `assets/js/data.js`；加队员、换照片、填赛程都不用碰 HTML。 |

## 二、文件结构

```
site\
├── index.html              首页
├── about.html              战队介绍
├── players.html            选手阵容
├── player.html             选手详情模板（?id= 参数区分队员）
├── matches.html            赛事记录
├── media.html              素材库
├── follow.html             关注我们
├── test.html               素材自检页（诊断用，可删）
├── 使用说明.md             给站长的上手说明（含素材复制清单）
├── README.md               本文件
└── assets\
    ├── css\style.css       全站样式：主题变量、动画、响应式、打印
    ├── js\
    │   ├── data.js         ★ 数据层 —— 日常改这个
    │   └── main.js         行为层 —— 主题、导航、双语、动画、图集
    └── media\              ★ 素材（70 个文件，已就位）
        ├── 队伍徽章\
        ├── 选手照片\
        ├── 选手印花\
        ├── 选手签名\
        ├── 队服\
        ├── 入场动画\
        └── 合影\
```

**全站只有 `player.html` 一个详情模板**，通过 `player.html?id=YangC` 渲染对应队员，
所以加人、改名都不需要新建文件。

## 三、功能

### 页面

| 页面 | 内容 |
| --- | --- |
| 首页 | 首屏徽章光环、战队主张、在册队员、团队合影、素材预览、关注入口 |
| 战队介绍 | `战队介绍.txt` 原文、理念三则、队内约定、历程时间线 |
| 选手阵容 | 7 人卡片，可按指挥 / 突破手 / 狙击手 / 自由人筛选 |
| 选手详情 | 个人资料、印花与签名（点击放大）、上下一位切换 |
| 赛事记录 | 六列表格结构已就绪，数据在 `data.js` 的 `MATCHES` 里填 |
| 素材库 | 队徽动画 × 3、入场动画、队徽版本 × 9、队服与合影、选手印花与签名 |
| 关注我们 | B 站频道主卡片、发布内容、其他渠道、常见问题 |

### 外观

- 右上角按钮循环切换 **跟随系统 → 黑夜 → 白天**，选择记在 `localStorage`
- 深色 / 浅色两套变量名一致，组件只引用变量，切换时全站配色平滑过渡
- 浅色主题的强调色自动压深一档，保证白底对比度
- 环境光晕在浅色下自动降饱和

### 双语

- 静态文字用 `data-i18n="key"` 标记，键值在各页底部的脚本里注册
- 动态渲染的内容（选手卡、表格、素材格、频道卡）在切换时整块重绘
- 首次访问跟随浏览器语言，之后记住选择

### 动效

环境光晕漂移、首屏逐级上浮、徽章双层反向旋转光环、滚动揭示自动错峰、
数字缓出计数、跑马灯无缝循环、卡片上浮 + 柔光、导航毛玻璃 + 渐变进度条。

全部在 `prefers-reduced-motion: reduce` 下自动关闭。

### 素材兜底

| 情况 | 表现 |
| --- | --- |
| 某张照片缺失 | 自动尝试该队员的下一张候选照片 |
| 该队员所有照片都缺失 | 自动改用印花 |
| 印花也缺失 | 显示 ID 首字母的大号渐变占位 |
| 素材库里某张图缺失 | 图框内显示「素材未加载」，不出现破图图标 |
| 有多张素材读不到 | 右下角浮出一条提示，列出需要复制到的目录结构，并链到自检页 |
| 一切正常 | 页面上不存在任何提示元素 |

## 五、改配色的地方

`assets/css/style.css` 顶部两组变量，改一处全站生效：

| 变量 | 深色 | 浅色 | 用途 |
| --- | --- | --- | --- |
| `--bg` / `--bg-soft` | `#05070d` / `#080b14` | `#f7f9fd` / `#ffffff` | 页面底色 |
| `--cyan` → `--indigo` | `#22d3ee` → `#6366f1` | `#0e9bb8` → `#4c4ee0` | 全站唯一的强调色渐变 |
| `--text` / `--text-soft` / `--text-mute` | 三级文字层次 | 同结构 | 正文层次 |
| `--ease` / `--t-base` | `cubic-bezier(.22,.61,.36,1)` / `.42s` | 同左 | 全站统一缓动 |

只把 `--cyan`、`--sky`、`--blue`、`--indigo` 四个值换掉，渐变、按钮、
标题、进度条会一起跟着变，动效不用动。

## 六、更新素材后会看到的行为

改完 `data.js` 或换掉素材文件后，建议依次检查：

1. `test.html` —— 素材是否全部可读
2. `players.html` —— 每位队员的照片或印花是否显示；点进详情页是否正常
3. `media.html` —— 视频滚进视口是否自动播放；图片点击能否放大
4. 右上角外观按钮 —— 三种模式是否都正常
5. 右上角 CN / EN —— 文案是否完整
6. 窗口缩到手机宽度 —— 汉堡菜单、抽屉、单列卡片是否正常
